# Character Gallery

## Language

**Character library**:
The collection of a person's saved Characters, regardless of what a search shows.

**Gallery**:
The view used to browse Characters from the library. A search can show some or none of them without changing the library.

**Backup**:
One file that carries a whole Character library, so its Characters can be restored later or on another origin.
_Avoid_: export, archive, snapshot

**Restore**:
Recreating Characters in a library from a Backup.
_Avoid_: import, load, upload

**Image download**:
Handing one Character's image to the browser as a PNG file.
_Avoid_: export, image export

**Handoff**:
The browser has accepted a file from the page. It does not mean the file was saved.
_Avoid_: saved, completed, succeeded

**Lightbox**:
The view of one Character opened from the Gallery. It steps through the Gallery's current order.
_Avoid_: detail view, modal
